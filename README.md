# Personal Portfolio

My personal developer portfolio, built from scratch to showcase my projects, skills, and experience in software development.

🌐 **Live Website:** https://portfolio-29k.pages.dev/

## Tech Stack

- **React** – Building the user interface
- **TypeScript** – Type-safe JavaScript
- **Vite** – Development server and build tool
- **CSS** – Styling, layout, and responsiveness
- **Cloudflare Pages** – Hosting and automatic deployment
- **GitHub** – Version control

This portfolio is a work in progress. I'm building it incrementally, experimenting with modern web technologies and improving my frontend development skills along the way.
